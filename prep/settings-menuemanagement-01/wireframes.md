## Design Notes

### Theme Compliance
- All colors MUST use `theme.colors.*`
- All spacing MUST use `theme.spacing.*`
- All border radius MUST use `theme.borderRadius.*`
- NO hardcoded values allowed

### Component Size Limits
- Main components: max 300 lines
- Modal components: max 250 lines
- Card components: max 150 lines
- Utility components: max 100 lines

### Accessibility
- All interactive elements must have `accessibilityLabel`
- All icons must have `accessibilityLabel`
- Color contrast must meet WCAG AA standards
- Touch targets minimum 44x44 points
