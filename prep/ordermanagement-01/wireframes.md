# Order Management - Wireframes

## Overview

This document contains detailed ASCII wireframes for all screens in the Order Management system.

---

## 1. Ordering Screen (Main Screen) - 3-Panel Layout

### Screen Architecture

The ordering screen uses a **3-Panel Layout**:
1. **LEFT PANEL** - Categories (Combo at the end)
2. **CENTER PANEL** - Menu Items Grid
3. **RIGHT PANEL** - Order Cart & Billing

### Panel Details

#### PANEL 1: Categories (Left Side)
- Fixed width: 140px
- Scrollable if many categories
- "All Items" at top
- Regular categories in order
- **COMBOS always at the bottom** (visually distinct)

```
┌─────────────────┐
│                 │
│    ALL ITEMS    │  ← Show all menu items
```

#### PANEL 2: Menu Items (Center)
- Flexible width (~55% of screen)
- Search bar at top
- Grid of menu item cards
- 3-4 items per row depending on screen size
- Scrollable

#### PANEL 3: Order & Billing (Right Side)
- Fixed width: 300px
- Order details header
- Scrollable item list
- Fixed billing summary at bottom
- Action buttons
