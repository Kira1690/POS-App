This document details all user flows in the Order Management system, from table selection to payment completion.

| Status | Color | Actions Available |

### Quick Add vs Modifier Selection

```
IF item has required modifiers:
    → Open Modifier Selection Modal
    → User must complete selections
    → Add to cart

ELSE IF item has optional modifiers only:
    → Quick add to cart (quantity 1)
    → Show "Customize?" option in cart item
    → User can tap to open modifier modal

ELSE (no modifiers):
    → Quick add to cart immediately
    → Increment quantity if already in cart
```
