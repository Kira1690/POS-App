┌──────────────────────────────────────────────────────────────────┐
│ 🚀 MAIN COMMAND (Start here!)                                    │
└──────────────────────────────────────────────────────────────────┘

    ./test-on-emulator.sh

    This will:
    ✓ Start the Android tablet emulator (if not running)
    ✓ Build your POS app
    ✓ Deploy it to the emulator
    ✓ Launch the app automatically


┌──────────────────────────────────────────────────────────────────┐
│ 📋 OTHER USEFUL COMMANDS                                         │
└──────────────────────────────────────────────────────────────────┘

    ./test-on-emulator.sh --clean        # Clean build
    ./test-on-emulator.sh --restart      # Restart emulator first
    ./test-on-emulator.sh --logs         # Show logs after deploy

    ./view-logs.sh                       # View app logs
    ./stop-emulator.sh                   # Stop the emulator
    ./clean-all.sh                       # Clean all caches
